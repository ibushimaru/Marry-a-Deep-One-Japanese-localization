# Marry a Deep One 日本語化キット

Steam版『Marry a Deep One』の文字列を日本語に差し替えるためのキットです。ゲーム本体は含みません。`translation/sample_ja.csv` に156件の試訳を収録しています。全訳ではなく、未訳の箇所は英語のまま表示されます。`translation/translation.csv` は翻訳作業用の空欄CSVです。

## サンプル訳をゲームに入れる

1. Steam版ゲームをインストールし、ゲームを終了します。すでに別のMODを入れている場合は、Steamの「インストール済みファイルの整合性を確認」で原本に戻します。
2. このZIPを展開し、`START.bat` をダブルクリックします。Pythonのインストールやネット接続は不要です。`START.bat` は同梱の `MarryTool.exe` を起動します。Steamのライブラリ設定からゲームを自動検出します。見つからない場合だけゲームフォルダーを入力してください。複数見つかった場合は番号を選びます。対応版の原本 `data.win` は、キット内の `game_backup/data.win.orig` にバックアップされます。
3. メニューで `1 サンプル訳を反映` を選びます。CSV検査、ビルド、ゲームへの反映まで自動で進みます。完了の表示を確認してからゲームを起動してください。

**`START.bat` を開くだけでは反映されません。** メニューの `1` を選ぶ必要があります。通常はゲームフォルダーの入力は不要です。ビルドには少し時間がかかります。

原本へ戻すには、ゲームを終了して `START.bat` の `4 原本に戻す` を選びます。Steamの整合性確認でも原本に戻せます。

## 注意点

`translation/translation.csv` の `ja` 列に訳文を入力し、UTF-8のCSVで保存します。他の列は変更しません。未訳行は空欄のままで構いません。`translation/sample_ja.csv` は訳例として参照できますが、試訳なので文体や用語の正解ではありません。空欄の元データが必要なら `translation/template.csv` を参照してください。

訳文を反映するときは、ゲームを終了して `START.bat` の `2 作業用CSVを反映` を選びます。CSV検査、ビルド、反映を続けて実行します。検査だけなら `3` です。修正後も同じ操作で上書きできます。ビルドは毎回原本から行うため、前回の訳文は混ざりません。

`sample_ja.csv` と `translation.csv` は別です。メニューの `1` はサンプルを反映し、`2` は作業用CSVを反映します。`1` を選んでも作業用CSVの編集内容は消えません。

### CSVの見方

| 列 | 内容 |
|---|---|
| `id` | 文字列の識別番号。不具合の報告にも使用 |
| `en` / `ja` | 英語原文 / 日本語訳 |
| `category` / `script` | 分類 / 参照するスクリプト |
| `route` | 描画方法。枠や折り返しの目安 |
| `width_px` | 描画時に指定される幅。空欄のラベルには既知の枠幅がない |
| `concat` | `yes` は実行時に他の文字列と連結される可能性あり |
| `placeholders` | 訳文にも残す `{main_he}` などの記号 |
| `translate` | `no` は内部処理にも使う可能性があるため訳さない |
| `note` | 解析時の注意。推定を含む |

`{main_he}` などのプレースホルダーは、綴りと個数を変えずに残します。日本語の語順に合わせて位置は移せます。`#` はゲーム内の改行、`##` は空行を含む区切りです。通常は原文と同じ個数にしてください。`concat=yes` の行だけは必要なら `#` を増やせます。CSVセル内に実際の改行を入れないでください。`translate=no` の行は空欄のままにします。

`route=event` の本文はゲーム内で折り返し、`draw_ext` はビルド時に折り返します。`label` と `name` は基本的に折り返しません。ラベルの表示枠の空き幅は自動判定できないため、原文より長いという理由だけで訳を縮める必要はありません。訳した場面を実機で確認してください。文体は原文の視点・話者・感情の強さを基準にし、英語の `you` を毎回「あなた」「お前」にする必要はありません。

## 困ったとき

対応しないゲームの版や別MODが入っている場合は、安全のため反映を停止します。Steamの「インストール済みファイルの整合性を確認」で原本に戻してから再実行してください。それでも止まる場合は、キットがその版に対応していません。

CSV検査は、列・行、プレースホルダー、`#`、フォント未収録文字などを確認します。表示枠への収まりは判定しません。エラーが出た場合は表示全文、該当 `id`、ゲームの版を記録してください。ゲーム起動中は反映・復元できません。

コマンドラインから使う場合は、`MarryTool.exe` の `locate`、`init`、`check`、`build`、`install`、`restore` を使用できます。`check` と `build` は `--csv` で対象ファイルを指定できます。配布ZIPにはゲーム本体、パッチ済み `data.win`、各PCで生成する `game_backup/`・`build/`・`workspace/` は含みません。フォントとライセンスは `fonts/` に同梱しています。
