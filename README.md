# Marry a Deep One 日本語化キット

Steam版『Marry a Deep One』を日本語化するためのキットです。ゲーム本体は含まれていません。156件の試訳が入っていますが、未訳の箇所は英語のまま表示されます。

入手する際は、[Releases](https://github.com/ibushimaru/Marry-a-Deep-One-Japanese-localization/releases)から`Marry-a-Deep-One-Japanese-kit.zip`をダウンロードしてください。GitHubの「Code → Download ZIP」はソースコード用で、実行ファイルが入っていません。

## サンプル訳をゲームに入れる

1. Steam版のゲームをインストールし、終了しておきます。別のMODを入れている場合は、Steamの「インストール済みファイルの整合性を確認」で原本に戻してください。
2. 配布ZIPを展開し、`START.bat`をダブルクリックします。ゲームはSteamのライブラリから自動で探します。見つからなければゲームフォルダーを入力してください。複数見つかった場合は番号を選びます。
3. メニューの`1 サンプル訳を反映`を選びます。処理が終わったら、ゲームを起動して表示を確認してください。

`START.bat`を開くだけでは日本語化されません。メニューで`1`を選ぶと、CSV検査、ビルド、ゲームへの反映が順に進みます。ビルドには少し時間がかかります。Pythonのインストールやネット接続は不要です。

初回実行時には、対応する原本の`data.win`をキット内の`game_backup/data.win.orig`に保存します。原本に戻す場合は、ゲームを終了してからメニューの`4 原本に戻す`を選んでください。Steamの整合性確認でも戻せます。

## 注意点

翻訳する場合は、`translation/translation.csv`の`ja`列に訳文を入力し、UTF-8のCSVで保存してください。他の列は変更しません。未訳行は空欄で構いません。`translation/sample_ja.csv`には試訳が入っています。文体や用語は確定していません。空欄の元データは`translation/template.csv`にあります。

訳文をゲームに入れるときは、ゲームを終了してからメニューの`2 作業用CSVを反映`を選びます。CSV検査、ビルド、反映が順に進みます。検査だけなら`3`を選んでください。訳文を直したあとも、同じ操作で反映できます。毎回原本からビルドするため、前回の訳文は残りません。

メニューの`1`はサンプル訳、`2`は作業用CSVを使います。`1`を選んでも、作業用CSVの編集内容は消えません。

### CSVの見方

| 列 | 内容 |
|---|---|
| `id` | 文字列の識別番号。不具合の報告にも使います |
| `en` / `ja` | 英語原文 / 日本語訳 |
| `category` / `script` | 分類 / 参照するスクリプト |
| `route` | 描画方法。枠や折り返しの目安になります |
| `width_px` | 描画時に指定される幅。空欄のラベルは枠幅が不明です |
| `concat` | `yes`の場合は他の文字列とつながることがあります |
| `placeholders` | 訳文に残す`{main_he}`などの記号 |
| `translate` | `no`の場合は訳さないでください。内部処理にも使われる可能性があります |
| `note` | 解析時の注意。推定も含みます |

`{main_he}`などの記号は、綴りと個数を変えずに残してください。日本語の語順に合わせて位置を動かすことはできます。`#`はゲーム内の改行、`##`は空行を含む区切りです。原則として原文と同じ個数にしますが、`concat=yes`の行では必要に応じて`#`を増やせます。CSVのセルに実際の改行は入れないでください。`translate=no`の行は空欄のままにします。

`route=event`の本文はゲーム内で折り返し、`draw_ext`はビルド時に折り返します。`label`と`name`は基本的に折り返しません。ラベルの空き幅は自動で判定できないため、原文より長いという理由だけで訳を縮める必要はありません。訳した箇所はゲームで確認してください。

文体は原文の視点・話者・感情の強さに合わせます。英語の`you`を毎回「あなた」「お前」と訳す必要はありません。

## 困ったとき

誤って上書きしないため、対応していない版や別のMODのデータには反映しません。Steamの「インストール済みファイルの整合性を確認」で原本に戻してから、もう一度実行してください。それでも止まる場合、その版には対応していません。

CSV検査では、列・行、プレースホルダー、`#`、フォントにない文字などを調べます。表示枠に収まるかどうかは判定しません。エラーが出た場合は、表示された文面、該当する`id`、ゲームの版を記録してください。ゲーム起動中は反映・復元できません。

コマンドラインから使う場合、`MarryTool.exe`には`locate`、`init`、`check`、`build`、`install`、`restore`があります。`check`と`build`では`--csv`で対象ファイルを指定できます。

配布ZIPにはゲーム本体やパッチ済みの`data.win`は含みません。各PCで作る`game_backup/`、`build/`、`workspace/`も入っていません。フォントとライセンスは`fonts/`に同梱しています。
